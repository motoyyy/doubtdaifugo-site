# サポート

「ダウト大富豪」をご利用いただきありがとうございます。

本ページでは、不具合報告やお問い合わせ方法についてご案内します。

## 1. お問い合わせ先

運営：Ludivela Games

メール：  
ludivelagames.support@gmail.com

お問い合わせへの返信には時間がかかる場合があります。

## 2. 不具合をご報告いただく際に記載してほしい情報

不具合についてお問い合わせいただく場合は、可能な範囲で以下の情報をご記載ください。

- アプリ名：ダウト大富豪
- アプリのバージョン
- 使用している端末
- iOSのバージョン
- 不具合が発生した日時
- 不具合が発生するまでの操作手順
- 発生した現象
- 再現性の有無
- 必要に応じてスクリーンショット

これらの情報があると、不具合の確認や調査を行いやすくなります。

## 3. お問い合わせ時のお願い

お問い合わせの際は、以下の情報を送信しないようお願いいたします。

- パスワード
- クレジットカード番号
- その他の決済情報
- 不要な個人情報

Ludivela Gamesから、メールでパスワードやクレジットカード番号をお尋ねすることはありません。

## 4. よくあるお問い合わせ

### アプリが正常に動作しません

以下をお試しください。

1. アプリを一度終了して再起動する
2. 端末を再起動する
3. iOSが最新の状態か確認する
4. App Storeでアプリの更新がないか確認する

改善しない場合は、上記のお問い合わせ先までご連絡ください。

### ゲームのルールが分かりません

アプリ内の「遊び方」をご確認ください。

### 購入・課金について

現行バージョンではアプリ内課金機能は提供していません。

将来課金機能を追加した場合は、本ページの内容も更新します。

### 広告について

現行バージョンでは広告を掲載していません。
